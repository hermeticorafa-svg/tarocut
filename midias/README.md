# midias/

Fotos e gráficos avulsos — **não cartas do baralho** — para a sintaxe do
roteiro escrito à mão no modo cartas do editor:

```
[1:29] grafico.png; 12s              # entra na pilha da direita
[3:02] mapa-astral.jpg; full; 8s     # tela cheia, cartas somem e voltam
```

Só entra no autocomplete e no export o que estiver aqui dentro, com
extensão `.jpg`, `.jpeg`, `.png` ou `.webp` — ver `catalogo_midias()` em
`tarocut.py`. Não crie subpastas: a busca não é recursiva.
